      ⚙️ AI 配置

      Key 仅存本地，不会上传到任何第三方。
      📍 怎么拿 Claude API Key：
      1. 打开 console.anthropic.com/settings/keys
      2. 登录 → 点 Create Key → 复制（只显示一次！）
      3. 粘贴到上面的输入框 → 保存配置
      ⚠️ 需要先在 Billing 充值（最少 $5）。这是按 token 计费，不是 Pro 订阅。

      📍 OpenAI Key： platform.openai.com/api-keys

      💬 对话

      💡 AI 能做什么
      • "今天深蹲 100kg×5 三组" → 自动写入训练记录
      • "我体重 70.5" → 自动写入身体数据
      • "早餐吃了两个鸡蛋一杯牛奶" → 自动写入饮食
      • "今天膝盖有点酸" → 写入日志的不适记录
      • "分析一下我最近的训练" → AI 读取你的数据并给建议
      • "帮我设计下周计划" → AI 根据你的目标输出计划
